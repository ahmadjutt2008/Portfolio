# Portfolio Website

A modern, responsive personal portfolio website designed to showcase skills, projects, and contact information. Built with a mobile-first approach using HTML5, CSS3, JavaScript, and Bootstrap 5.

## 🚀 Features

-   **Responsive Design**: Fully responsive layout that looks great on all devices (Mobile, Tablet, Desktop).
-   **Modern UI**: Clean and professional interface using Bootstrap 5 and custom CSS.
-   **Interactive Elements**: Smooth scrolling navigation, hover effects, and interactive project cards.
-   **Project Showcase**: dedicated section to highlight featured projects with images and descriptions.
-   **Skills Visualization**: Progress bars to visually represent technical proficiency.
-   **Contact Section**: Integrated contact form UI and social media links.

## 🛠️ Technologies Used

-   **HTML5**: Semantic markup for structure.
-   **CSS3**: Custom styling and layout improvements.
-   **Bootstrap 5**: Responsive framework for rapid UI development.
-   **JavaScript (Vanilla)**: For interactive behavior and functional scripts.
-   **Font Awesome**: For high-quality icons.
-   **Google Fonts**: "Inter" and "Poppins" for modern typography.

## 📂 Project Structure

```
Portfolio/
├── assets/          # Images and static assets
├── index.html       # Main HTML file
├── style.css        # Custom CSS styles
├── script.js        # JavaScript functionality
└── README.md        # Project documentation
```

## 🔧 Setup & Usage

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/ahmadjutt2008/Portfolio.git
    ```
2.  **Navigate to the project directory**:
    ```bash
    cd Portfolio
    ```
3.  **Open `index.html`**:
    Simply open the `index.html` file in your preferred web browser to view the portfolio.

## 🎨 Customization

To personalize this portfolio:

1.  Open `index.html` in a code editor.
2.  Update the content within the tags (e.g., Change "John Doe" to your name).
3.  Replace images in the `assets/` folder with your own (Keep filenames consistent or update paths in HTML).
4.  Modify `style.css` to adjust colors and fonts to match your brand.
